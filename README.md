# Umbral

Archivo de juegos personal para Windows. Reúne juegos de PC, emuladores y ports en una biblioteca con carátulas, tiempos de juego y lanzamiento directo.

## Descargar

Última versión: https://github.com/sanjurjogon-crypto/umbral/releases/latest

1. Descarga `Umbral.exe`.
2. Colócalo en una carpeta con permisos de escritura, como Descargas. Evita carpetas sincronizadas con OneDrive.
3. Ábrelo. Windows puede avisar por ser un ejecutable sin firma: "Más información" y "Ejecutar de todas formas".

Desde la 8.15.0, Umbral comprueba si hay versiones nuevas y se actualiza desde Ajustes. Los datos (biblioteca, horas, ajustes y carátulas) se guardan en `%APPDATA%\Umbral`, separados del ejecutable.

## Versiones

Cada versión se publica en Releases con su ejecutable y su hash SHA-256. La actualización descarga el nuevo ejecutable, verifica el hash, hace una copia de seguridad de los datos y reinicia Umbral.
